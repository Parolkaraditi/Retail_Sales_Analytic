
# Retail Sales Analytics

## Project Overview
An end-to-end Retail Sales Analytics project using Python, MySQL, Excel, and Power BI to analyze sales performance and generate business insights.

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- MySQL
- Excel
- Power BI
- DAX

## Project Structure
- data/ - Raw and cleaned datasets
- python/ - Data cleaning and analysis scripts
- sql/ - SQL business analysis queries
- excel/ - Excel analysis and dashboard
- powerbi/ - Power BI dashboard
- results/ - EDA and advanced analysis outputs

## Key Business Metrics
- Total Revenue: ₹135,700
- Total Orders: 6
- Total Customers: 6
- Average Order Value: ₹22,616.67

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Product and category revenue analysis
- Monthly sales analysis
- City-wise revenue analysis
- Customer revenue analysis
- Interactive dashboards
